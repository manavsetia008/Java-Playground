# Java Playground

A collection of Java projects built to strengthen programming fundamentals, from simple console programs to bigger applications.

## 📂 Projects

### Calculator
A menu-driven calculator that performs basic arithmetic operations.

**Concepts used:** Switch statements, Loops, Input validation

### Number Guessing Game
A console-based game where the user guesses a random number with selectable difficulty levels (Easy, Hard, Unlimited).

**Concepts used:** Random number generation, Loops, Conditionals, User input/output

### Rock Paper Scissors
A console-based game where the player competes against the computer.

**Concepts used:** Random number generation, Loops, Conditionals, Strings

### To-Do List Manager
A simple task manager to add, view, complete and remove tasks. Tasks are saved to a file.

**Concepts used:** Collections, Inner classes, Loops, File handling

## ▶️ How to Run
1. Clone the repository:
```
   git clone https://github.com/manavsetia008/Java-Playground.git
```
2. Open the project in IntelliJ IDEA
3. Open any project's main class and click Run

## 🛠️ Requirements
- JDK 17 or higher
- IntelliJ IDEA (or any Java IDE)
